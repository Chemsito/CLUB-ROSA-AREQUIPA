# Club Rosa Arequipa

Página de reservas de masajes a domicilio en Arequipa. Los clientes eligen servicio, masajista, fecha, hora y distrito; la solicitud se envía por WhatsApp al negocio.

- **Servicios:** 30 min S/ 75 · 1 hora S/ 135 · 2 horas S/ 195
- **Taxi:** S/ 15 (cercana), S/ 20 (media), S/ 25 (lejana)

## Configuración
Edita el bloque `CONFIG` al inicio de `script.js` para cambiar el número de WhatsApp, precios, zonas, distritos y masajistas.

## Publicación
Sitio estático servido con GitHub Pages desde la rama `main`.
