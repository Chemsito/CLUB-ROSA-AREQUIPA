# Club Rosa Arequipa

Página de reservas de masajes a domicilio en Arequipa. Los clientes eligen servicio, masajista, fecha, hora y distrito, e indican su dirección pegando un link de Google Maps o marcándola en un mapa (OpenStreetMap, sin clave); la solicitud se envía por WhatsApp al negocio.

- **Servicios:** 30 min S/ 75 · 1 hora S/ 135 · 2 horas S/ 195
- **Taxi:** S/ 15, precio único a cualquier distrito

## Configuración
Edita el bloque `CONFIG` al inicio de `script.js` para cambiar el número de WhatsApp, precios, taxi (`taxi`), distritos y masajistas.

## Publicación
Sitio estático servido con GitHub Pages desde la rama `main`.
